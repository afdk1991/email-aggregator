## 修复的上一轮遗留 bug（全量测试才暴露）

1. **EWS `IncrementalSync` 编译错误**：`cursor.InternalDate` 在 `SyncCursor` 无此字段 → 改用 `cursor.HighWaterMark`（时间型协议的高位水位）并补 `strconv`。（`src/connector/ews.go`）
2. **EWS 解析返回 0 邮件**：`findItem/getItem` 响应结构跳过了真实 EWS 信封里的 `ResponseMessages` 包装层 → 补该层并修正访问路径。（`src/connector/ews.go`）
3. **LocalKms 信封加密 nonce 丢失**：`aesGCMSeal` 用 `gcm.Seal(nil, iv, …)` 把 IV 丢弃，导致解密把密文当 nonce 全红 → 改为 `gcm.Seal(iv, iv, …)` 前置 nonce。4 个 `TestLocalKms_*` 由全红转全绿。（`src/security/local_kms.go`）
4. **LocalKms 权限测试 Windows 误报**：`0o600` 断言在 Windows 无意义 → 改为 `runtime.GOOS != "windows"` 时才断言（生产 Linux 仍生效）。（`src/security/local_kms_test.go`）
