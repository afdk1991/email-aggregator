## 二、策略：零依赖、构建标签隔离

沙箱硬约束：**无 Docker / 无活服务 / GOPROXY 离线 / 零新依赖**。据此采用：

- **结构化日志**：`log/slog`（标准库）JSON handler，自动携带 `trace_id` / `tenant_id` / `account_id`。
- **进程内指标注册表**（自研，标准库）：`Counter`（带标签维度）+ `Histogram`（简化 P95）+ `Registry`/`Default()` 全局单例 + `Snapshot()` 导出。
- **Prometheus exposition 隔离**：用 `//go:build integration` 把真实 exposition 文本导出器隔离在 `prometheus.go`，默认构建不含它（保持默认构建纯标准库、无对外依赖）。
- **多租户贯穿**：`octx` 经 HTTP → 编排 → 摄取 → AI 网关贯穿埋点日志（对齐 ADR-009）。

## 三、落地内容

### 3.1 新增 `src/observ/` 包

| 文件 | 职责 |
| --- | --- |
| `log.go` | `octx` 上下文、`WithTraceID` / `WithTenant` / `TraceID`、`Logger(ctx)`（自动带字段）、`Info` / `Warn` / `Error` |
| `metrics.go` | `Counter`（Inc/Add/Value/Snapshot，带标签）、`Histogram`（Observe/Count/Sum/P95/Snapshot）、`Registry`（Counter/Histogram/Snapshot）、`Default()` 单例；**8 个预定义业务指标**（见下） |
| `prometheus.go` | `//go:build integration`：`Registry.PrometheusExposition()` 零依赖手渲 HELP/TYPE/counter/histogram(count+sum+p95)，可挂载 `/metrics` 供 Prometheus 抓取 |
| `observ_test.go` | 4 测试：`TestTraceAndTenantContext` / `TestCounterIncAndSnapshot` / `TestHistogramP95`(1..100→95) / `TestDefaultRegistryShared`，全过 |

**预定义业务指标（对齐蓝图 SLI）**：

- `sync_syncs_total{tenant,account,provider,status}` — 同步任务总数 / 成功率
- `sync_duration_ms{tenant,account,mode}` — 同步时延 P95
- `ingest_mails_total{tenant,account,status}` — 摄取吞吐
- `ingest_duration_ms{tenant,account}` — 单封摄取时延
- `ai_calls_total{tenant,capability,backend,allowed,redacted}` — AI 调用 / 命中后端 / 脱敏命中
- `ai_duration_ms{backend}` — AI 调用时延 P95
- `ai_errors_total{tenant,backend}` — AI 失败
- `connector_errors_total{tenant,account,provider}` — 上游连接器错误

### 3.2 四条关键路径埋点接入（替换散落 `fmt.Printf`）

| 文件 | 埋点 |
| --- | --- |

### 3.3 HTTP / 集成挂载

- **默认构建**：`/api/health` 返回 `{ok, goroutines, metrics(snapshot)}`；`/api/metrics`（JSON 快照）当 `WithObserv` 挂载时可用；`traceMiddleware` 全程注入 `X-Trace-ID`。
- **integration 构建**（`cmd/server_integration.go`）：额外挂载 `/metrics`（text/plain Prometheus exposition），可直接被 Prometheus 抓取、接 Grafana（对齐蓝图 §10）。

### 3.4 新增 API 层测试 `src/api/observ_http_test.go`（3 测试 PASS）

- `TestHealthWithObserv_DetailAndMetrics`：`/api/health` 含 `metrics` + `goroutines` + `X-Trace-ID`；`/api/metrics` 含 counters/histograms。
- `TestTraceIDPassthrough`：客户端 `X-Trace-ID` 原样透传进 ctx。
- `TestMetricsEndpoint_NotMounted`：未挂载时 `/api/metrics` 路由未注册（返回 404）。
